# ⚖️ Legal RAG App

## Features
- ChatGPT-like UI
- Chat history
- PDF upload
- Legal Q&A (RAG)

## Setup

1. Install dependencies:
pip install -r requirements.txt

2. Install Ollama:
https://ollama.com

3. Pull model:
ollama pull llama3

4. Run app:
streamlit run app.py

## Optional
Run ingest.py to preload Constitution PDF.
